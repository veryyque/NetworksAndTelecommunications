# Multicast Delivery

Лабораторная работа по дисциплине **«Сети и Телекоммуникации»**.

## Описание

Приложение обнаруживает другие запущенные копии самого себя в локальной сети с помощью multicast UDP.

Программа отслеживает появление и исчезновение других экземпляров приложения и при изменении состава участников выводит список IP-адресов активных копий + UUID.

Программа принимает на вход один или два аргумента командной строки: IP мультикаст группы, или IP + название сетевого интерфейса. В первом случае программа автоматиески определяет доступный сетевой интерфейс, во втором подключается к интерфейсу введенному пользователем (если такой интерфейс доступен, иначе - ошибка).

Приложение поддерживает работу как с IPv4, так и с IPv6 и автоматически выбирает нужный протокол в зависимости от переданного адреса multicast-группы.

## Сборка и запуск

Запуск через терминал с ручной сборкой: 

```Bash 
swiftc MulticastDelivery/*.swift -o multicast
./multicast <ip>
```
или
```Bash 
./multicast <ip> <interface>
```
Запуск через Xcode - открытием файла MulticastDelivery.xcodeproj
